==================================================
GENERAL REQUIREMENTS
==================================================

The platform is designed for accountants before submitting Accounting Memos to internal or external auditors.

This is NOT a chatbot.

This is NOT an IFRS search engine.

The platform acts as an AI Pre-Audit Assistant that evaluates accounting analyses using IFRS/IAS standards, assesses Professional Judgment, identifies missing evidence, predicts auditor concerns, and provides actionable recommendations.

The UI should look like a Deloitte, PwC, EY, or KPMG enterprise application.

Minimal.

Professional.

Modern.

Banking-grade.

Keep the current blue and white theme.

KNOWLEDGE BASE CONTENT
==================================================

Populate every IFRS / IAS standard page with accurate structured reference information.

DO NOT leave any standard page empty.

DO NOT generate fictional accounting guidance.

DO NOT invent IFRS paragraphs.

Each standard page must contain:

• Standard Number
• Official Standard Name
• Objective
• Scope
• Recognition Principles
• Measurement Principles
• Presentation Requirements
• Disclosure Requirements
• Key Professional Judgment Areas
• Common Auditor Review Points
• Practical Business Examples
• Related Standards
• Frequently Asked Questions
• Important Definitions
• Effective Date
• Latest Amendment Status

Display the information as structured summaries rather than copying the full official standard.

Every section should clearly indicate the relevant IFRS paragraph numbers where applicable.

Include a footer:

"Based on IFRS Foundation guidance."

Provide a button:

View Official Standard

which links to the official IFRS Foundation website.
